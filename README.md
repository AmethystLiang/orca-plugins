# OLED Pair

True black and true white themes for [Orca](https://github.com/stablyai/orca), with matching terminal colors.

| Theme | Base | Notes |
| --- | --- | --- |
| OLED Dark | Pure black | An unchanged copy of the Orca OLED theme |
| OLED Light | Pure white | Mirrors the dark greys, with code colors tuned for white and slightly quieter hover and selection |

## Use it

Install it from Settings → Plugins, then go to Settings → Appearance and choose OLED Dark and OLED Light. Choose the terminal themes with the same names under Terminal.
